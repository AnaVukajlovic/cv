Izdvojeni projekti

Pravoslavni Svetionik – Full-Stack Web aplikacija (Master rad)

Full-stack web aplikacija posvećena digitalizaciji i interaktivnom prikazu srpskog kulturnog i duhovnog nasleđa — pravoslavnih manastira u Srbiji, dinastije Nemanjić kao najvećih zadužbinara i ključnih istorijskih perioda Srbije i SPC. Sistem omogućava pregled detaljnih profila manastira i ktitora, hronološko i tematsko istraživanje istorije, kao i naprednu pretragu i filtriranje sadržaja.

Projekat je razvijen u Laravel ekosistemu uz primenu AI-assisted metodologije za generisanje i optimizaciju koda, kao i integraciju Ollama (lokalnog LLM modela) i Groq API servisa za obradu i strukturiranje istorijskih podataka.

Napomena o produkcionoj verziji: Zbog ograničenja resursa na besplatnom cloud paketu, live verzija na Render platformi ne pokreće lokalni LLM model u realnom vremenu, već strukturirane podatke brzo i pouzdano servira direktno iz relacione baze podataka. Pri prvom otvaranju besplatnom serveru može biti potrebno 30–50 sekundi za pokretanje.

  • Kompletna Laravel MVC backend arhitektura i modularni Blade/JS korisnički interfejs
  • Projektovanje relacione baze podataka (povezivanje manastira, ktitora, epoha i istorije)
  • Integracija Ollama i Groq API (LLM) platformi za AI obradu podataka tokom razvoja
  • REST API komunikacija, pretraga i dinamičko filtriranje sadržaja
  • Verzionisanje koda na GitHub-u i cloud deployment na Render platformi

Tehnologije: PHP, Laravel, Blade, MySQL / SQLite, JavaScript (ES6+), HTML5, CSS3, Ollama, Groq API, GitHub, Render

SrbijaManastiri – Desktop aplikacija (Diplomski rad)

Objektno-orijentisana edukativna desktop aplikacija za prikaz pravoslavnih manastira u Srbiji, razvijena u WinForms okruženju sa fokusom na stabilnost, sigurnu prijavu korisnika i pouzdan rad sa relacionom bazom podataka.

  • Bezbedna autentifikacija i upravljanje korisničkim ulogama (Admin / Korisnik)
  • Kompletne CRUD operacije nad sadržajem aplikacije
  • Rad sa bazom podataka kroz ADO.NET i SQL Server LocalDB
  • Galerija fotografija, istorijske priče, kalendar, kviz znanja i brza pretraga

Tehnologije: C#, .NET Framework, WinForms, SQL Server (LocalDB), ADO.NET
